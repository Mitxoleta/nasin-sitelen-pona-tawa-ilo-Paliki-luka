# nasin-sitelen-pona-tawa-ilo-Paliki-luka
A toki pona sitelen pona IME for Fcitx5, compactible with [nasin-nanpa](https://github.com/etbcor/nasin-nanpa) 5.0 and above. sitelen Lasina taso.

# Installation
- Place the corresponding files under appropriate folders in `home/.local/share`.
- Select "sitelen pona" in Fcitx Configuration.
Tips: run `libime_tabledict tok.txt tok.dict` if you want to rebuild the `.dict` file..
